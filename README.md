<https://github.com/AetherBella/Project-Portfolio>

## Notes

- No build step and no framework. The page is plain HTML, CSS and vanilla JavaScript.
- Every figure about my own work comes from my resume.
- The two Tableau views are live embeds and load only when you click them, so nothing is
